# NLP News Analysis

Natural Language Processing project focused on text preprocessing, named entity recognition, rule-based matching, and statistical text analysis using Python and spaCy.

---

## Features

- Text preprocessing
- Tokenization
- Stopword removal
- Named Entity Recognition (NER)
- Rule-based pattern matching
- Bag of Words analysis
- N-gram analysis
- Word frequency visualization
- Statistical text analysis

---
